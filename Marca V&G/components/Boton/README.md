# Botón

Acción principal y secundarias en el sitio web y en los sistemas internos. **Primario** (relleno `accent`, texto `on-accent`) una sola vez por vista, para la acción que justifica la página. **Secundario** con borde `line-strong` para el resto. **Texto** en `accent-text` para acciones menores. Verbo en infinitivo y en mayúscula inicial: "Solicitar cotización", "Ver propuesta". Esquinas `radius-md` (4px) como máximo; el foco es un anillo `focus-ring` de 2px.
