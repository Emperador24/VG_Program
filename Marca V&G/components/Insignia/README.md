# Insignia

Estado de un proyecto, servicio u orden de trabajo en una o dos palabras. El color está en el punto, no en el fondo, para que el texto siempre sea `ink` legible: **En planificación** `secondary`, **En ejecución** `accent`, **Completado** `success`, **Suspendido** `danger`. Texto en estilo `etiqueta` (mayúsculas, tracking amplio). Nunca uses el color solo: la palabra siempre acompaña al punto.
