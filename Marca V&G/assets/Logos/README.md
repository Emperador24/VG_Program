# Logos

Versiones del sello oficial de V&G Proyectos y Servicios, C.A., todas derivadas del arte original (sin redibujar). PNG con fondo transparente a 1510 px.

- `vg-logo-blanco.png` — tinta blanca #FFFFFF. Versión principal, sobre negro crudo, azul petróleo o fotografía oscura.
- `vg-logo-negro.png` — tinta #0E0F11. Sobre hueso, blanco y papel.
- `vg-logo-ambar.png` — tinta #D4A03A. Solo sobre negro, en piezas especiales.
- `vg-logo-original.jpg` — arte original recibido (blanco sobre negro). Solo referencia.

Nota: la gota dentro del barril es un hueco transparente; deja ver el fondo, por eso el logo solo funciona sobre fondos sólidos o fotografías con una franja sólida detrás. Para impresión de gran formato (rotulado, bordado) se recomienda vectorizar el sello a partir de estos archivos.
