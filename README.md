# V&G Proyectos y Servicios - Sistema de Control

Sistema web integral para gestionar gastos diarios por máquina, nómina de operarios, y análisis financiero.

## Estructura del Proyecto

```
V&G/
├── api/              # Backend Node.js + Express
├── app/              # Frontend React + Vite
├── docs/             # Documentación
└── README.md         # Este archivo
```

## Stack Tecnológico

- **Frontend**: React + Vite
- **Backend**: Node.js + Express/Fastify
- **Base de datos**: PostgreSQL
- **Almacenamiento**: Cloudinary/S3
- **Reportes**: PDFKit + ExcelJS

## Configuración Rápida

### Backend
```bash
cd api
npm install
npm run dev
```

### Frontend
```bash
cd app
npm install
npm run dev
```

## Fases de Desarrollo

1. **Fase 1**: MVP Básico (Usuarios, Máquinas, Gastos, Dashboard)
2. **Fase 2**: Nómina e Ingresos
3. **Fase 3**: Reportes Automáticos
4. **Fase 4**: Análisis Financiero
5. **Fase 5**: Facturación SENIAT
